# 可复用技能包

用于多机联调、DMA 事务、实时性能定位和黄金结果比对的工作流与脚本。各子目录的 `README.md` 提供使用说明，`SKILL.md` 提供大模型工作流。

## 技能列表

| 技能 | 适用场景 | 使用入口 | 适用边界 |
|---|---|---|---|
| [主机—目标机联调](host-target-bringup/README.md) | 启动位置、部署文件或服务连接异常 | 部署配置与文件检查脚本 | 静态检查不验证服务、驱动和硬件 |
| [DMA 事务与排错](dma-transaction-debug/README.md) | 流式加速器的收发、缓存和超时问题 | 通道与缓冲事务模板 | PYNQ Simple AXI DMA，固定长度输出 |
| [实时瓶颈定位](realtime-bottleneck-profile/README.md) | 计算较快但显示或主循环卡顿 | 分段计时与日志分析 | 仅分析已记录的阶段和计时区间 |
| [黄金比对与取证](golden-evidence-audit/README.md) | 输出语义、报告版本或计时口径不一致 | 二进制比对与证据采集脚本 | 需要明确数据契约、报告格式和样本对应关系 |

## 使用

1. 将整个 `skill/` 或所需子目录复制到自己的工程，按实际接口替换示例路径、数据类型、长度和硬件名称。
2. 按对应 README 运行随包示例，替换自己的路径、数据契约和设备配置。合成示例只用于理解工具输入与输出。

3. 接入实际数据或设备前，先用已知答案的小样本核对结果。使用大模型时，提供该项 `SKILL.md`、接口说明和原始日志。
